# BlushAgency

Run a small ecommerce brand from Claude Code. Type `/blushagency` and you get this week's three actions, your blockers and one next step. Department agents draft the work. You approve it.

## What you get

- A chief-of-staff skill that reads your plan, checks your Shopify store and reports status.
- 33 agents for content, email, paid social, SEO, support, pricing and QA.
- One firm rule: agents draft, you approve. Nothing sends, posts, spends or changes a price without your yes.

## Install

1. Copy `blushagency/` to `~/.claude/skills/`.
2. Copy `agents/*.md` to `~/.claude/agents/`.
3. Restart Claude Code and type `/blushagency`.

## Before you use it

Connect your own Shopify, FLORA and treg accounts. Then replace `blushagency/plan.md` with a plan for your store. The one in this repo is a sample.
