# BlushAgency
A Claude Code skill plus department agents that run a small ecommerce brand: weekly status, routing work to agents, drafts only. Nothing goes live without the owner's approval.

Install: copy `blushagency/` to `~/.claude/skills/` and `agents/*.md` to `~/.claude/agents/`, restart Claude Code, type `/blushagency`.
Needs your own Shopify, FLORA and treg connections. Edit `plan.md` for your own store.
